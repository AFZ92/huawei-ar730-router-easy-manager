# Huawei AR730 Router Easy Manager

**أداة سطح مكتب بواجهة رسومية لإدارة التحكم بالوصول على راوتر Huawei NetEngine AR730 — عبر SSH، دون معرفة أي أمر من أوامر VRP.**

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)
[![Python 3.9+](https://img.shields.io/badge/python-3.9%2B-blue.svg)](https://www.python.org/downloads/)

> 🇬🇧 [English README](README.md)

موظف الاستقبال لا ينبغي أن يعرف `aaa` و `local-user` و `cut access-user` كي يُدخل طابعة إلى
الشبكة. هذه الأداة تحوّل تلك العمليات إلى أزرار، وتفرض قواعد الترتيب التي يشترطها الجهاز
صامتاً، وتتحقق من كل كتابة بإعادة قراءة الإعداد، وتحفظ محلياً **لمن** يعود كل عنوان ماك — وهو
ما لا يستطيع الراوتر تخزينه.

تأتي مع **محاكي راوتر كامل يعمل بلا شبكة**، فتستطيع تقييمها والتدرّب عليها قبل أن تلمس أي
جهاز حقيقي.

## ما الذي تفعله

| التبويب | الوظيفة |
|---|---|
| **الأجهزة الموثوقة** | إضافة وإزالة عناوين ماك من القائمة البيضاء مع اسم وصفي. الجهاز المسجَّل يدخل الشبكة **بلا صفحة تسجيل دخول** — مناسب للكمبيوترات والطابعات والكاميرات ونقاط الوصول. |
| **حسابات البوابة** | إنشاء وحذف حسابات Captive Portal، وتغيير كلمات السر ومجموعات الصلاحيات. هذا هو المناسب للهواتف. |
| **المتصلون الآن** | من هو متصل، بأي IP وماك، وحالته. مع زر لفصل أي جلسة، وزر لتوثيق جهاز متصل مباشرة. |
| **مجموعات الصلاحيات** | عرض المجموعات ورقم الـACL المرتبط بكل واحدة وعدد الأعضاء. |
| **البحث** | تصفية حيّة في كل الجداول بالماك أو الاسم أو الحالة أو المجموعة أو الـIP. مطابقة الماك تتجاهل الفواصل. |
| **سجل الأوامر** | كل أمر أُرسل وكل رد جاء من الراوتر. |

**الواجهة بالعربية والإنجليزية**، مع انعكاس كامل للتخطيط في العربية (RTL) لا مجرد ترجمة نصوص.

## جرّبه قبل أن تلمس الشبكة

```bash
python ar730_qt.py --demo
```

بلا `paramiko` وبلا أي اتصال شبكي. المحاكي يفرض قواعد الجهاز الحقيقي: يرفض الترتيب المقلوب،
ويرفض كلمة سر تساوي اسم المستخدم، ويرفض `irreversible-cipher`، ويسأل `[Y/N]` عند الحفظ.
شريط العنوان يكتب **DEMO** كي لا يلتبس الوضعان. هذا هو المكان الذي يتدرّب فيه الموظف الجديد.

## التثبيت

يحتاج **Python 3.9 أو أحدث**.

```bash
git clone https://github.com/AFZ92/huawei-ar730-router-easy-manager.git
cd huawei-ar730-router-easy-manager
pip install -r requirements.txt
python ar730_qt.py
```

تشغّل ملفات `run.sh` و`run.bat` واجهة Qt الرسمية مباشرةً.

## مزامنة البيانات بين أجهزة الإدارة (Firebase)

يبقى البرنامج عاملاً دائماً ببياناته المحلية. ويمكنه، اختيارياً، حفظ أسماء الأجهزة والحسابات
والسجل في Firebase Firestore ومزامنتها تلقائياً مع أجهزة الإدارة الأخرى: عند كل تعديل، وعند
بدء التشغيل، وكل دقيقة أثناء التشغيل. إذا انقطع الإنترنت، يحفظ التعديل محلياً ويحاول رفعه لاحقاً.

1. أنشئ مشروع Firebase وقاعدة **Cloud Firestore**، ثم أنشئ service account مخصصاً له أقل
   صلاحيات Firestore اللازمة لبيئتك.
2. في Firestore Rules اسمح لهذا الحساب الموثق بقراءة وكتابة مستند البرنامج فقط، مثلاً:

```text
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /ar730_manager/shared_state {
      allow read, write: if request.auth != null;
    }
  }
}
```

3. من تبويب **الإعدادات** اضغط «استيراد بيانات اعتماد Firebase»، واختر ملف JSON الخاص بـ
   service account، ثم اضغط «مزامنة Firebase الآن». ينسخ التطبيق الاعتماد محلياً بصلاحيات
   مقيّدة؛ ولا يعرض المفتاح الخاص أو يسجله أو يرفعه إلى Firestore.

إن لم تستورد اعتماداً، لن يستخدم البرنامج Firebase وسيبقى التخزين محلياً فقط. لا تُرفع كلمة مرور
SSH أو كلمة مرور حسابات MAC المشتركة أو ملف service account. تبقى طريقة Web API Key القديمة
مدعومة للتثبيتات القائمة فقط.

## قواعد يفرضها البرنامج تلقائياً

كل واحدة منها سلوك حقيقي في VRP كلّف أحدهم وقتاً:

1. **ترتيب الأوامر إلزامي** — `service-type` ثم `password` ثم `user-group`.
2. **كلمة سر الماك مشتركة ولا تساوي اسم المستخدم.**
3. **`cipher` لا `irreversible-cipher`.**
4. **المجموعة إلزامية** — حساب بلا مجموعة يحصل على وصول **غير مقيّد**.
5. **تغيير الصلاحيات لا يسري على جلسة قائمة** — لذلك يُتبع كل تغيير بأمر `cut`.
6. **التحقق بعد كل كتابة** — يُعاد قراءة الإعداد للتأكد، ولا يُستنتج النجاح من غياب الخطأ.
7. **الحفظ تلقائي** بعد كل تغيير ناجح.

## الإلغاء لا يعني الحذف

عند إلغاء جهاز يُحذف من الراوتر فعلاً ويفقد الوصول فوراً، لكنه يبقى في السجل المحلي بحالة
«ملغى» مع التاريخ والسبب، بلون رمادي. فيبقى لديك أثر لمن كان لديه وصول ومتى سُحب.

## إعداد مهم

`mac_shared_password` في تبويب الإعدادات **يجب أن تطابق حرفياً** ما هو مضبوط في الراوتر:

```
mac-access-profile name m_wl
 mac-authen username macaddress format without-hyphen password cipher <القيمة>
```

إن اختلفت، لن يدخل أي جهاز موثوق وسترى `Local username or password is wrong`. هذا هو السبب
الأشيع لمشكلة «وثّقت الجهاز ولم يتصل».

## التطبيق المكتبي

واجهة Qt هي التطبيق الرسمي الوحيد لإدارة الراوتر. ثبّت المتطلبات وشغّل وضع
التجربة أو الوضع الحقيقي من نفس البرنامج:

```bash
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python ar730_qt.py --demo
```

ولتشغيل الاختبارات دون راوتر:

```bash
QT_QPA_PLATFORM=offscreen .venv/bin/python harness/run_qt_test.py
```

الاختبارات تستعمل راوتر AR730 وهميًا يتكلم VRP، وتغطي الواجهة الكاملة بلا شاشة
وبلا عتاد.
